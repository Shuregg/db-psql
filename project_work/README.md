# Project work - Hospital Database

## 1. Описание структуры базы данных

База данных "Больница" предназначена для управления информацией о пациентах, врачах, отделах, комнатах, диагнозах, визитах и лекарствах. Она может быть использована администрацией больницы, врачами и другим медицинским персоналом для ведения учета и управления медицинскими данными.

Ниже представлена структурная схема спроектированной базы данных

![Структурная схема](db_chemastic.svg)

## 2. Возможные запросы пользователей

* Получение информации о отделениях больницы, их глав, помещениях.
* Получение информации о пациентах, их диагнозах и визитах.
* Получение информации о врачах и их специализациях.
* Получение информации о помещениях и их типах.
* Получение информации о лекарствах, их количестве, их назначении.

## 3. Возможные ограничения (что можно улучшить)

* Отсутствует более общая таблица "employees" (персонал), во множество которой входили бы не только врачи, но и другие сотрудники больницы.

## 4. Работа с мейкфайлом

Для создания таблиц, триггеров, индексации, процедур и пр.

```bash
make create
```

Для заполнения таблиц готовыми предопределенными значениями

```bash
make fill_tables
```

Для запуска n-го запроса

```bash
make query NUM=${NUM}
```

Пример:

```bash
make query NUM=01
make query NUM=03
make query NUM=15
```

Название файла с содержанием SQL запроса должно быть

```bash
query_{NUM}.sql
```

где `{NUM}` - номер запроса (напр. 01, 02, ..., 20).

Для запуска 20 первых запросов

```bash
make
```

## Существующие процедуры

1. Добавление пациента `add_patient`

2. Добавление врача `add_doctor`

3. Добавление нового диагноза `add_diagnosis`

4. Добавление посещения `add_visit`

5. Добавление нового препарата `add_medication`

## Существующие триггеры и их функции

* Автоматический подсчёт количества полных лет пациента

    ```sql
    calculate_age()
    update_age_trig
    ```

* Установка в `NULL` количества коек, если тип помещения не является палатой

    ```sql
    set_number_of_beds_null()
    set_number_of_beds_null_trig
    ```

* Проверка свободных мест в палате

    ```sql
    check_room_capacity()
    check_room_capacity_trig
    ```
